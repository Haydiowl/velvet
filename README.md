# Velvet Aesthetics Homepage

Static, responsive Velvet Aesthetics homepage with a client-sourced featured treatment catalogue and functional cart foundation.

## Deploy to Vercel

1. Upload this folder to GitHub with `index.html` at the repository root.
2. In Vercel, choose **Add New Project** and import the repository.
3. Leave **Framework Preset** as `Other`.
4. Leave the build command empty.
5. Set the output directory to `.` or leave it empty.
6. Deploy.

The included `vercel.json` keeps the project configured as a static site. The project does not require npm, a build command, or environment variables.
